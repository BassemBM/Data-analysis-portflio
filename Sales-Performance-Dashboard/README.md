# Sales Performance Dashboard

## 📊 Project Overview

An interactive Power BI dashboard designed to analyze e-commerce sales performance and provide clear business insights.

## 🎯 Objective

The goal of this project is to analyze sales data and understand business performance across products, cities, categories, sales channels, and payment methods.

## 🛠️ Tools & Technologies

- Python
- Pandas
- Power BI
- Data Analysis
- Data Visualization

## 📌 Key KPIs

- Total Sales
- Total Orders
- Total Quantity
- Total Customers
- Average Order Value

## 📈 Analysis

The dashboard analyzes:

- Sales trends over time
- Sales by city
- Sales by product
- Top 5 products by sales
- Sales by category
- Sales by sales channel
- Sales by payment method

## 🎛️ Dashboard Features

- Interactive Date Range
- City Filter
- Category Filter
- Sales Channel Filter
- Payment Method Filter
- Interactive visualizations
- KPI cards

## 💡 Key Insights

The dashboard helps identify the highest-performing products, cities, sales channels, and payment methods, supporting better business decisions.
